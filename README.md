# Ruchi Thosar — Technical Product Manager

A static portfolio with product case studies, user journey diagrams, and a résumé.

The site uses HTML, CSS, SVG, images, and a PDF. It has no backend or database.

## Publishing

GitHub Pages serves the main branch from the repository root. Commit changes to publish updates.

## Editing

Edit index.html for the homepage and the individual HTML files for each case study. Styling is in site.css. Images and the résumé are stored alongside the pages.
